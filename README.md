# 🥊 복싱 인터벌 타이머 PWA

GitHub Pages에 바로 배포하여 스마트폰 홈 화면에 설치할 수 있는 복싱 인터벌 타이머 웹 앱입니다.

## 비프음 구성
- **운동 시작**: 긴 비프음 1회
- **운동 종료 30초 전**: 삐- 삐- (2회)
- **휴식 시작**: 긴 비프음 1회
- **휴식 종료 10초 전**: 삐삐삐 (3회)
- **마지막 라운드 종료**: 긴 비프음 3회

## GitHub Pages 배포 방법
1. 이 폴더의 모든 파일(`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`)을 GitHub 저장소(Repository) 최상단에 업로드합니다.
2. 저장소의 **Settings > Pages** 메뉴로 이동합니다.
3. **Branch**를 `main` (폴더 `/root`)으로 설정하고 **Save**를 누릅니다.
4. 생성된 `https://<아이디>.github.io/<저장소이름>/` 주소로 스마트폰에서 접속한 뒤 **홈 화면에 추가**를 누르면 앱으로 설치됩니다.
