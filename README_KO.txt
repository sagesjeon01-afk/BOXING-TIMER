복싱 타이머 PWA 설치 안내
==========================

포함 기능
- 기본 3분 운동 + 30초 휴식 자동 반복
- 운동 종료 30초 전 비프음/진동
- 휴식 종료 10초 전 비프음/진동
- 라운드 수: 무제한, 3, 5, 10, 12, 15
- 운동 시간: 2, 3, 4분
- 화면 켜짐 유지(Wake Lock 지원 브라우저)
- 광고/로그인/외부 분석 코드 없음
- 서비스워커 캐시를 통한 오프라인 실행

중요한 제한
PWA는 Android/Chrome의 백그라운드 제한을 받을 수 있습니다.
화면을 끄거나 다른 앱으로 전환했을 때 타이밍과 소리가 항상 보장되지는 않습니다.
화면 켜짐 유지 옵션을 켜고, 실제 운동 전에 기기에서 테스트하세요.
알림/소리는 브라우저와 기기 설정에 영향을 받습니다.

GitHub Pages로 무료 배포하는 방법
1. github.com 에 로그인하고 새 Repository를 만듭니다.
2. 공개(Public) 저장소로 만들고 이름은 boxing-timer 등으로 지정합니다.
3. 이 압축파일의 파일과 icons 폴더를 저장소 최상위(root)에 업로드합니다.
4. 저장소 Settings > Pages로 이동합니다.
5. Build and deployment에서 Deploy from a branch를 선택합니다.
6. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
7. 잠시 후 표시되는 https://계정명.github.io/저장소명/ 주소를 Android Chrome으로 엽니다.
8. Chrome 메뉴(⋮) > 앱 설치 또는 홈 화면에 추가를 누릅니다.
9. 한 번 앱을 열어 캐시를 만든 뒤 비행기 모드에서도 실행되는지 확인합니다.

업데이트
파일을 수정해 저장소에 다시 올리면 배포 후 새 버전이 적용됩니다.
서비스워커 캐시 갱신에 시간이 걸릴 수 있으니 앱을 완전히 닫았다가 다시 여세요.
